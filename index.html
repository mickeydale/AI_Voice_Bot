🚀 Universal Zero-Setup Architecture

This voice bot was architected to be 100% user-friendly for non-technical evaluators:

  • No API Keys: Operates using zero-configuration browser-native AI (Puter.js) backed by high-speed serverless fallback endpoints.
  • Real Voice Input & Output: Uses the Web Speech API (SpeechRecognition + SpeechSynthesis) with zero latency audio streams.
  • Live Dynamic Persona: Speaks in the 1st person ("I") representing the candidate, accurately addressing all core questions and unpredictable follow-ups.
  • Editable On-the-Fly: The candidate or reviewer can open "Persona Settings" to view or modify answers in real time.

🎙️ How to Test:

  1. Click the circular glowing Microphone Button and grant microphone permission when prompted.
  2. Speak your question naturally (or click any of the 5 Question Cards).
  3. The bot will stream the transcript, think, and speak back the answer with animated sound waves!
